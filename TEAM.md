`owner.html` sits with Kushal because it is a staff dashboard (same layout as admin).

## How to work without clashes
1. Clone / pull the GitHub repo.
2. Edit **your** HTML / JS / CSS only.
3. Commit with your name in the message, e.g. `Kushal: login form validation`.
4. Push, then tell the group so they can pull.

## Shared (do not rewrite alone)
- `js/app.js` — login, roles, cart helpers, header
- `js/data.js` — product list
- `css/styles.css` — shared look (header, buttons, cards)

To change look of **your page only**, put CSS in your own `css/<name>.css` file.
